# 생기부 세부능력 및 특기사항 기재 요령

> AI가 세특 문구를 **생성할 때마다 이 지침을 그대로 따른다.**
> 규칙을 바꾸려면 **이 파일을 고치고 배포(main push)** 하면 다음 생성부터 반영된다.
> (읽기 실패 시에도 생성은 멈추지 않고, 코드에 내장된 동일한 기본 규칙으로 작성한다.)

## 문체
- **현재형 종결어미 `~함`** 으로 끝낸다. 과거·미래시제, `~했음 / ~하였음 / ~할 수 있음 / ~알 수 있었음` 은 쓰지 않는다. → `~함`, `~앎`.
- 교사의 입장에서 **관찰한 사실 위주**로 서술한다. 학생의 감정·속마음·추측은 쓰지 않는다.
- 중학생 수준의 쉬운 표현을 쓴다.

## 분량·형식
- **약 2문장**으로 간결하게 쓴다.
- **줄바꿈 없이**, 문장과 문장 사이는 **띄어쓰기 한 칸**으로 이어 쓴다.
- 공백 포함 **200자 안팎**.
- 활동을 **전부 나열하지 말고 대표 활동 1~2개**로 압축한다.

## 금지
- **특정 회사·제품·브랜드·서비스·앱 이름을 쓰지 않는다. 일반 명칭으로 바꾼다.**
  - 예: 파이썬 → **텍스트 프로그래밍 언어** / 특정 디자인 앱 → **디자인 도구** / 특정 생성형 AI 서비스 → **생성형 AI** / 마이크로비트 → **소형 코딩 보드(피지컬 컴퓨팅 도구)** / 특정 설문·협업 도구 → **협업 도구**
- 점수·등급·석차·우열 표현을 넣지 않는다.
- **디지털 마음 톡톡(주제선택)**: 학생의 감정 글·마음일기 내용은 **절대 쓰지 않고**, 참여·활동 사실 수준으로만 서술한다.

## 끝맺음에 쓸 수 있는 종결어미 예시
활동함. 표현함. 설명함. 발표함. 제작함. 작성함. 관찰됨. 분석함. 실천함. 기록함. 구성함. 감상함. 비교함. 분류함. 구체화함. 선택함. 해석함. 활용함. 정리함. 연결함. 발견함. 서술함. 파악함. 계획함. 수행함. 적용함. 참여함. 공유함. 제출함. 질문함. 해결함. 완성함. 측정함. 등.
