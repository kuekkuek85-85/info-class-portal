- 날짜: 2026-11-01 (교사와 구상·확정. 제작은 informatics 담당, **교사 승인 후** 착수)
- 상태: **설계 확정(교사 최종 결정 반영, 2026-11-01)** — 단, 구현(seed/오프너/포털 컴포넌트/코드)·세션 오픈·커밋은 **다음 지시까지 금지(HARD-GATE)**.
- 아크 위치: 마이크로비트 아크 「주사위」 — 24차(두근두근)·25차(만보기) 다음. **25차 연장선**(흔들기 이벤트 이어붙이기).
  그 뒤 27차 = 가위바위보(별도 보관 문서 `2026-10-31-info-lesson27-rps-design.md`).

## 의도 (왜)

25차까지 학생은 **변수·대입·`show_number`·흔들기 이벤트(`on_gesture_shake` + `global` + `input.on_gesture`)·전체 코드 붙여넣기(바이브)** 를 익혔다. 26차는 **그 흔들기 이벤트에 이어붙여** "흔들면 주사위" 를 만든다. 새 개념은 **난수 `randint`** 와 **조건 분기 `if/elif/else`** 둘, 그리고 노가다를 줄이는 **포털 LED 생성 도구**. 25차와 같은 이벤트 뼈대를 재사용하므로 인지 부담이 적고, 핵심 배움(분기 로직)에 집중할 수 있다.

- 종착점(아크): 수행평가 = 각자 마이크로비트 피지컬 컴퓨팅 프로젝트. 26차는 '난수 + 조건 분기'를 체득하는 디딤돌.
- 실패 신호(교사 지론): 바이브/붙여넣기만 하면 얕다 → **분기 로직은 학생이 직접** 짜고, **디버깅 미션 1개**로 25차 개념(이벤트·global·randint 위치)을 다시 눌러 확인.

## 목표 / 비목표

- 목표: ① `randint(1,6)` 로 주사위 굴리기(흔들기 이벤트 안), ② 숫자→주사위 눈 **`if/elif/else` 분기**를 직접 작성, ③ `show_leds`(포털 도구로 받은 눈 패턴)·`show_number` 출력, ④ 바이브로 작은 기능(6이면 소리·불빛) 얹기.
- 비목표: 긴 코드, 픽셀 수작업 타이핑, 주사위 2개/점수 누적(바이브 확장은 허용), createAI(수행평가 후 보너스).
- 적은 줄 원칙: 반복되는 LED 그리기·이벤트 등록 줄은 **완성/도구 제공**, **핵심(randint 호출·분기)만 빈칸**.

## 제약 / 관례 (아크 규칙 그대로)

- **25차 코드 이어붙이기** — 25차 만보기 완성 코드(흔들기 핸들러)를 주고 그 안을 바꿔 주사위로. 25차와 같은 `microbit-makecode` 통.
- 새 스타터 코드 **복사 허용(등폭 `code` 필드)** + **빈칸 채우기**. 빈칸 = **오른쪽 `# 한글 미션 주석` + 왼쪽 빈자리**. **‘___’ 금지**(블록 변환 불가 — 25차 실측), **빈 함수 본문엔 `pass`**.
- 힌트는 정답 영어 키워드 직접 쓰지 말고 **뜻으로**(예: randint → "무작위로 하나 뽑아 주는 '임의'를 뜻하는 함수"). 숫자 값 빈칸(1·6 등)은 그대로 둬도 됨.
- 표준: 대기 = **파이썬 타자 도우미**(link:), freeNavigation **off**, hideDoneButton **true**, 기분체크 **on**, 성찰 제출 → **보상 게임 = 사과(fruit-box, https://fruit-box-game-delta.vercel.app/)**. 구현 단계마다 **실행결과 이미지(SVG, 설명 우측 1/3 폭)**. 제출칸 `long` maxLength 넉넉(**6000**).
- activityId = `microbit-makecode`. 공유 링크 비공개(갤러리 off).

## 확정 사항 (교사 확정 — 이대로 반영)

게임 = 마이크로비트 **주사위**. 25차 흔들기 이벤트(`on_gesture_shake` + `global`)에 **이어붙이기**. 새 개념 = `randint`·`if/elif/else`·포털 LED 생성 도구.

- **미션1**: 흔들면 `randint(1, 6)` → 그 숫자를 `show_number` 로 그대로 출력(주사위 '숫자판'). 25차 코드 붙여넣기 + 오른쪽 한글 미션 주석·왼쪽 빈칸 방식.
- **미션2 ★최종 변경★**: 주사위 **눈(점 모양)** 출력. 도구 성격이 '패턴만 생성'이 아니라 **전체 프로그램 생성 도구**로 바뀜. 학생은 ① `if/elif/else` **분기를 드롭다운으로 조립**(조건 "숫자 == N" → 출력 "아래에서 그린 눈 N"), ② 각 눈은 **5×5 격자에 직접 그림**(위 표준 눈 보고 따라 찍기), ③ **'코드 생성'** 누르면 **완성된 MakeCode 정적 파이썬 전체 코드**(흔들기 이벤트 + randint + if/elif/else + show_leds)가 나옴. **손 타이핑 없이 조립→생성**(노가다 방지, 교사 의도). → 생성 코드는 **복사 → MakeCode 붙여넣기 → 실행**으로 확인. **별도 제출칸 없음** — '코드 생성' 누르면 세션에 자동 저장.
- **미션3**: 바이브 코딩으로 **"6이 나오면 소리·불빛"** 기능 얹기(`vibe_code`, vibeTarget `microbit` — 25차 3단계 재사용).

## 미션 구성 (given vs 빈칸) — **미션 4개**(교사 T1 확정: 디버깅을 별도 미션으로)

phaseOrder: `waiting → assessment(안내) → build(미션1) → grill(미션2) → problem(미션3·디버깅) → mvp(미션4·바이브) → reflection`.
phaseLabels: build=「미션1 숫자 주사위」, grill=「미션2 주사위 눈(도구)」, problem=「미션3 버그 고치기」, mvp=「미션4 AI로 기능 추가」.
(네 번째 미션 슬롯으로 `problem`(인간과AI용 범용 worksheet 단계)을 빌려 씀 — 25차 build·grill·mvp 관례의 연장. 구현 때 `problem` 단계가 worksheet 문항을 렌더하는지 확인, 안 되면 다른 빈 슬롯으로 교체.)

### 미션1 (build) — 흔들면 숫자 주사위
- **given(완성 제공)**: 25차 흔들기 뼈대 — `roll = 0` 변수, `def on_gesture_shake(): global roll`, `input.on_gesture(Gesture.SHAKE, on_gesture_shake)` 등록 줄, `show_number` 자리 설명.
- **빈칸(학생)**: 흔들기 핸들러 본문에서 ① **`randint(1, 6)` 호출해 변수에 저장**(난수 신개념), ② 그 변수를 `show_number` 로 출력. (값 범위 1·6은 주석으로 제시 — 이해 불필요한 숫자.)
- 실행결과 이미지: 흔들 때 숫자 1~6이 바뀌는 SVG(우측 1/3).

### 미션2 (grill) — 숫자를 주사위 눈으로 (★전체 프로그램 생성 도구, T2=자유 그리기)
- **방식(교사 최종)**: 손으로 분기문을 타이핑하지 않는다. **포털 신규 도구(주사위 코드 조립기)** 로 처리.
- **학생이 하는 일**: ① 1~6 각 숫자의 **눈을 5×5 격자에 직접 그린다**(옆에 **표준 눈 1~6 '기준 눈' 참고 이미지**를 띄워 보고 따라 찍기 — 올바른 눈 모양 익히기), ② **`if/elif/else` 분기를 드롭다운으로 조립**한다(조건 "숫자 == N" → 출력 "내가 그린 눈 N"). 분기의 '구조'(어떤 숫자에 어떤 눈)를 **이해해서 고르는 것**이 핵심 배움.
- **T2 = 자유 그리기 허용(교사 확정)**: 도구는 **일치검사·잠금 없음**. 학생이 그린 눈을 **그대로 코드화**(틀려도 생성됨). '기준 눈' 참고 이미지는 **보여주되 강제하지 않음**. **정확성은 교사 순회로 확인.**
- **도구가 하는 일**: '코드 생성' → **완성 전체 코드**(흔들기 이벤트 `on_gesture_shake` + `global` + `randint(1,6)` + 조립된 `if/elif/else` + 각 분기의 `show_leds`(학생이 그린 격자 그대로) + `input.on_gesture` 등록)를 뽑아 준다.
- **given / 빈칸 구분**: 이 미션엔 '코드 빈칸'이 없다 — **격자 그리기(6개) + 분기 드롭다운 조립**이 학생 몫, 코드 생성·문법은 도구가 담당.
- **제출**: 별도 제출칸 없음. '코드 생성' 시 세션에 **자동 저장**(교사 열람). 학생은 생성 코드를 복사 → MakeCode 붙여넣기 → 실행으로 확인.
- 실행결과 이미지: 숫자 대신 점(눈)이 뜨는 SVG(우측 1/3).

### 미션3 (problem) — 버그 고치기 (디버깅, 교사 T1 확정 · 별도 미션)
- **목적**: 바이브/도구만이면 얕다 → 25차 이벤트·`global` 이해를 **코드를 읽고 고치며** 다시 눌러 확인(교사 핵심 장치).
- **방식**: *"흔들어도 같은 숫자만 나온다"* 버그 코드를 **완성형으로 제공**(복사). 원인 = **흔들기 핸들러 안 `global roll` 누락**(바깥 `roll` 이 안 바뀜) 류. 학생이 **원인을 찾아 한 줄 고치고** → MakeCode 붙여넣기 → **흔들 때 숫자가 바뀌는지 실행 확인**.
- **빈칸/제출**: 코드 note(복사) + 짧은 제출칸(`long`, 고친 줄 또는 "무엇을 고쳤는지" 한 줄; maxLength 넉넉). 개념 확인 문항 1~2개(선택) — 예: "AI(주사위)가 매번 같은 수라면 `randint` 를 어디로 옮겨야 할까?", "`global` 을 빼면 왜 안 바뀔까?".
- 실행결과 이미지: 고치기 전(멈춘 같은 숫자) → 고친 후(바뀌는 숫자) 비교 SVG.

### 미션4 (mvp) — AI로 기능 얹기 (바이브)
- `vibe_code`(vibeTarget `microbit`) — 말로 부탁 → 주사위 전체 + 기능 코드 생성 → 복사해 MakeCode 붙여 실행. 25차와 동일 UX(생성 코드 패널 + MakeCode 열기, 프롬프트·답 저장, "선생님이 볼 수 있어요").
- **예시 문구 초안(내 결정, 25차처럼 3개 보여줌)**:
  - "6이 나오면 '삐' 소리가 나게 해 줘" (교사 기본 예시)
  - "6이 나오면 LED가 잠깐 반짝였다 눈을 보여주게 해 줘"
  - "A 버튼을 누르면 마지막에 나온 주사위 숫자를 다시 보여주게 해 줘"
- 바탕 코드: 서버 `vibe-code.ts` 에 **주사위 베이스**(MICROBIT_DICE_BASE) 추가 필요(25차 MICROBIT_MANBOGI_BASE 처럼 한곳 관리) — 구현 때.

## 새로 가르칠 개념 (쓰기 전에 가르침)

1. **난수 `randint(1, 6)`** — 범위 포함 개념. 25차 흔들기 이벤트 안에서 호출(연결 단서).
2. **조건 분기 `if / elif / else`** + 비교 `==` — 이번 핵심 신개념(숫자→눈 매핑).
3. (도구) **포털 주사위 코드 조립기** — 눈을 직접 그리고 분기를 드롭다운으로 조립 → 전체 코드 생성(손 타이핑 대신). 분기 '구조'는 학생이 이해해 선택.
→ 핵심 신개념은 **randint + if/elif/else 2개**. 이벤트·global·show_number·LED는 25차/도구로 흡수. if/elif/else 는 미션2에서 '타이핑' 대신 '드롭다운으로 구조를 조립'하며 익힌다.

## 포털 신규 도구 명세 — "주사위 코드 조립기" (범용 5×5 그리기 + 분기 조립, 27차 재활용)

- **목적(교사 최종)**: 픽셀·분기문 **수작업(노가다) 방지**. 학생이 **눈을 직접 그리고(올바른 모양 익히기) 분기를 드롭다운으로 조립**하면, 도구가 **완성된 MakeCode 전체 코드**를 생성. 타이핑은 빼되 '분기 구조 이해'는 남긴다.
- **재사용**: 27차 가위바위보에도 쓰도록 **범용**으로 — 5×5 그리기 + "조건 → 그린 그림" 분기 조립 틀을 공유(주사위 전용 아님). 주사위는 조건이 `숫자 == 1~6`, 가위바위보는 조건이 `내 패 == 가위/바위/보` 식으로 라벨만 바꿈.
- **박히는 위치**: 미션2(grill) 안의 **신규 위젯 문항**(단독). 미션1(코드 빈칸)·미션3(바이브)와 다른 세 번째 종류의 미션 UI.
- **학생 흐름**: (1) 화면에 **표준 눈 1~6 참고 표시**(아래 좌표)를 보며, (2) 1~6 각각 **5×5 격자를 클릭해 눈을 그림**, (3) **분기 드롭다운**으로 "숫자 == N → 눈 N" 6줄을 조립(또는 기본 제시된 매핑을 확인·수정), (4) **'코드 생성'** → 전체 코드 패널 + **복사 버튼**(+ MakeCode 열기 링크). 생성 시 **세션 자동 저장**.
- **입력**:
  - 5×5 토글 그리드 × **6개(눈 1~6)** — 각 칸 on/off(1/0). 참고 눈이 옆/위에 보임.
  - **분기 조립 UI** — 각 행 = [조건 드롭다운 "숫자 == 1…6"] → [출력 드롭다운 "내가 그린 눈 1…6"]. 기본값은 1→눈1 … 6→눈6으로 채워 두고 학생이 확인/변경(구조 이해).
