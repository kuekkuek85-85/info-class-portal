# 정보 33~34차 수행평가 「피지컬 컴퓨팅 프로젝트」 설계안 (안)

작성 2026-11-19. **설계안이다. lessonPlans·세션·푸시는 교사 결정 뒤.**
글은 블록당 3줄 이내, 시각화 우선. 대기=파이썬 타자, 되돌아가기 off, 마음 체크인 강제.

## 0. 확정 정보 (교사 제공)

- 개인 · 교사평가 · 실험·실습 · 오픈북 · **포털 AI만**(33~34차 모두) · 마이크로비트 실물 + 파이썬 코드 제출 · 전 과정 포털 자동 기록.
- 하드웨어: **본체 내장만** (버튼 A·B, 로고 터치, 기울기·흔들기, 빛, 온도, 소리 감지, 나침반 / LED 5×5, 스피커).
- 채점 ① 시스템 이해, ② 시스템 구현 - 상·중·하 문구는 32차 안내 탭과 같다(평가 계획 그대로).
- 교사가 원하는 4단계: ① 문제 발견·정의 → ② 구성요소 설계 → ③ AI로 구현하며 검토·비판적 사고 → ④ 성찰(기대 효과·장점, 확장·개선).

## 2. 단계 나누기와 근거

- 33차 = **생각하는 차시**(①②) + 구현 시작. 34차 = **만드는 차시**(③ 완성) + ④ 성찰.
- 근거: 채점 ① '이해' 는 문제·사례·구성요소 설명에서 나오고, 채점 ② '구현' 은 코드·오류 수정·동작에서 나온다.
  한 차시씩 나누면 33차 끝에 설계가 굳고, 34차는 구현에 몰입한다. 구현을 33차에 조금 시작해 두면
  34차 첫 10분을 "무엇부터 하지" 로 버리지 않는다.
- 33차 답은 학번별 공유 답안(artifacts/microbit-makecode__학번)에 mb33_* 키로 남고, 34차가 echoKeys 로 다시 보여 준다.

## 3. 33차 (45분) - 문제 발견 · 구성요소 설계 · 구현 시작

`phaseOrder: waiting → assessment → problem → mvp → grill → reflection`

| 단계 | 화면 | 시간 | 저장 키 |
|---|---|---|---|
| 대기·체크인 | 타자 링크 | 3 | - |
| 안내 (assessment) | 오늘 할 일 + **AI 사용 규칙**(32차 탭 재사용) | 3 | - |
| ① 문제 발견·정의 (problem) | 32차 성찰 echo → 내가 풀 문제(누가·언제·무엇이 불편) → 생활 속 피지컬 컴퓨팅 사례 1개와 그 가치 | 12 | mb33_problem, mb33_case, mb33_case_value |
| ② 구성요소 설계 (mvp) | 32차 고른 입력·출력 echo + 부품 그림(mb32-parts) → 입력·출력 고르기 → 입력 → 처리 → 출력 표 1~3줄 | 15 | mb33_in, mb33_out, mb33_flow(rows) |
| ③ 구현 시작 (grill) | 포털 AI 로 첫 코드 → **AI 검토 기록** 표(물어본 것 / 확인·고친 것 / 왜) | 10 | mb33_vibe, mb33_ai_log(rows) |
| 마무리 (reflection) | "오늘 정한 내 프로젝트를 한 줄로" (34차에서 echo) | 2 | mb33_summary (reflectionAnswerKey) |

- ① 의 '사례와 가치' 가 채점 ① 상("사례를 분석하여 필요성과 가치를 판단") 의 근거가 된다.
- ② 의 표(rows: 입력 · 처리 · 출력)가 채점 ① '구성요소·동작 원리 설명' 과 채점 ② '목적에 맞는 구성요소 선택' 의 근거.
- 그림: 기존 mb32-parts.svg · mb32-pa-flow.svg 재사용. 새로 필요: 33차 '오늘 할 일' 띠 그림 1장(선택).

## 5. AI 구현 단계 (③)

- 포털 vibe_code 를 쓴다. 보낸 말·받은 코드는 자동 저장되고 교사가 본다(학생 화면에 이미 표시).
- 학생은 **AI 검토 기록** 표만 짧게 쓴다: `물어본 것 | AI 답에서 확인·고친 것 | 왜`. 평가 계획의 'AI 활용 과정 표기' 를 채운다.
- 개인정보: AI 칸 바로 위에 1줄 "다른 사람 이름·연락처 등 개인정보는 넣지 않아요".
- **제약(중요): 지금 vibe_code 는 매번 '문항에 고정된 바탕 코드 + 이번 부탁' 으로 새로 만든다.**
  학생이 받은 코드를 다음 부탁에서 이어서 고칠 수 없다. 수행평가처럼 조금씩 쌓는 구현엔 맞지 않는다.
  - 제안: vibe 패널에 **"내 코드로 이어서 부탁하기"**(학생이 지금 코드를 붙여넣으면 그걸 바탕으로) 옵션을 더한다.
    서버는 길이·형식만 검사하고 학번·이름은 보내지 않는다(지금과 같다). 개발 반나절 정도, 질문 2.

## 6. 출발 코드 (상·중·하)

- 하: 지난 작품 예시 코드에서 고쳐 쓰기 / 중: 안내를 따라 / 상: 빈 코드에서 스스로.
- 제안: ③ 단계 위에 **예시 코드 5개**(하트 · 만보기 · 주사위 · 가위바위보 · 똥피하기)를 접어 둔 참고 칸으로 둔다(줄 번호·복사).
  - 5절의 "내 코드로 이어서" 가 있으면, 예시를 복사해 붙여넣고 AI 에게 바꿔 달라고 하면 된다 → 하 수준 학생도 출발 가능.
  - 없으면 예시별로 AI 칸을 따로 둬야 해서 화면이 길어진다.

## 7. 실물 동작 증거

| 방법 | 장점 | 걸림돌 |
|---|---|---|
| 학생이 동작 사진 1장 올리기 (image) | 기록이 남는다, 교사가 나중에 본다 | 사진이 공유 답안 문서(1MB 한도)에 들어간다 - 크기 줄여 저장(기존 기능) |
| 교사가 돌며 확인 체크 | 정확하다 | 체크하는 화면이 없다(새로 필요) |
| MakeCode 공유 링크 | 코드·시뮬레이터가 남는다 | 학교망·관리자 설정 확인 필요(캔바 링크 막힘 전례) |

- 추천: **사진 1장 + 동작 한 줄 설명**(필수) + 교사 채점 화면에서 '동작 확인' 체크(8절).

## 8. 교사 채점 화면

- 지금 있는 것: 대시보드의 학생별 활동지 보기, 세션별 AI 대화 보기(api/teacher/vibe-code).
- 없는 것: 학생 한 명의 **32~34차 산출물(문제·설계·AI 기록·오류 수정·최종 코드·사진·성찰) + AI 대화 + 상·중·하 채점**을 한 화면에서.
  - 발표 평가 화면(teacher/eval)은 「인간과 인공지능」 분반 전용으로 굳어 있다.
- 제안: **새 화면 「수행평가 채점」** - 반 선택 → 학생 목록 → 학생을 열면 단계별 카드 + AI 대화 + 최종 코드(줄 번호) + 사진,
  아래에 채점 ①·② 상·중·하 버튼과 메모. 점수는 학생 비노출 컬렉션(teacherEvals 와 같은 방식)에 저장.

## 9. 보상 게임 의견

- 의견: **수행평가 중에는 게임을 두지 않는 편을 권한다.** 일찍 끝낸 학생이 게임을 하면 아직 하는 학생이 흔들리고,
  '빨리 끝내기' 가 목표가 된다. 대신 일찍 끝낸 학생은 ④ 의 '확장 아이디어' 를 하나 더 써 보게 한다(가산 아님).
- 34차 마지막에 모두 제출한 뒤 교사가 열어 주는 방식이면 괜찮다(질문 1).

## 10. 공통 설정

- freeNavigation off(교사가 단계 운영), 마음 체크인 강제, hideDoneButton, 대기=타자 링크.
- focusExempt: waiting, grill(MakeCode 새 탭), build(사진 찍으러 카메라 앱).
- 33차 성찰 한 줄은 reflectionAnswerKey(mb33_summary)로 34차에 이어진다(32차와 같은 방식).
- 1-2·1-4 는 32차를 다른 판으로 들었어도 키(mb32_pa_problem · mb32_want_in · mb32_want_out)가 같아 33차 echo 가 똑같이 동작.

## 11. 교사 결정 질문

1. 보상 게임: 수행평가 중 **없음**(권장) / 34차 전원 제출 뒤 교사가 열기 / 평소처럼 성찰 뒤?
2. vibe 패널에 **"내 코드로 이어서 부탁하기"** 를 더할까? (없으면 매번 처음부터 다시 만든다)
3. 출발 코드: 지난 작품 **예시 코드 5개 참고 칸**을 둘까?
4. 실물 증거: **사진 1장 + 한 줄 설명**(권장) / 교사 체크만 / MakeCode 공유 링크(학교망 확인 필요)?
5. 교사 **「수행평가 채점」 새 화면**을 만들까? (상·중·하 입력·저장 포함)
6. 오픈북 범위: 지난 차시 '내 기록' 보기 허용? 교과서·검색은?
7. 1-2·1-4 의 34차 날짜(다음 주)가 정해지면 알려 주세요.
