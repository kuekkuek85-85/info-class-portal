# 정보 마이크로비트 아크 + 24차시 설계

- 날짜: 2026-10-22 (내일 10/23 1-3·1-1 정보 수업용)
- 교사와 브레인스토밍 후 확정. 제작은 informatics 담당에게 위임.

## 의도 (왜)

23차(마이크로비트 MakeCode 첫 LED — 두근두근 하트에서 **pause 못 하고 큰 하트·작은 하트 2줄까지만** 함)에 이어,
학생이 **자기 아이디어를 마이크로비트로 구현**하는 힘을 ~10차시에 걸쳐 쌓는다.

- **종착점(수행평가):** 각자 **자기 마이크로비트 피지컬 컴퓨팅 프로젝트** (오픈북, 코딩에 생성형 AI 도움 허용).
- **AI(createai.microbit.org, 움직임 데이터 학습):** 수행평가가 아니라 **수행평가 후 보너스/확장 활동**.

### 설계 원칙
- **움직임 중심**: 센서(특히 가속도·흔들기·기울기) 예제를 앞세워 이후 게임·프로젝트·createAI(움직임 학습)로 자연스럽게 잇는다.
- **적은 줄**: 23차에 한 차시 2줄 속도. 각 차시는 새 개념 1~2개, 짧게. ("많은 줄 코딩 불가" — 교사 확정 제약)
- **이어붙이기 + 빈칸 채우기**: 매 차시 **지난 시간 코드를 주고** MakeCode 파이썬 보기에 **붙여넣어 이어서**. 미션은 코드 안 **오른쪽 `# 한글 주석`** 으로 표시하고, **왼쪽 빈자리에 학생이 타이핑**. (23차 '직접 타이핑'에서 진화)
- 새 개념은 쓰기 전에 가르친다.

## 목표 / 비목표
- 목표: MakeCode 기본기(출력·반복·pause·소리·센서 입력·변수·조건·random·게임 루프)를 짧은 예제로 체득 → 수행평가에서 자기 프로젝트 구현.
- 비목표: 24차에 AI(createAI) 다루기(후반 보너스). 긴 코드·고난도.
- 실패 신호: 학생이 코드를 **안 읽고 붙여넣기만** 하는 것 → 그래서 '빈칸 채우기' 미션으로 읽게 만든다.

## 아크 (~10차시, 움직임 중심) — 차시 수는 느린 속도에 따라 유동(한 예제가 1~2차시)
1. **24차 두근두근 완성** — 반복·pause·소리·흔들기 이벤트  ← 이번 설계 대상
2. **만보기** — 가속도/흔들기 + 변수 세기 + 표시
3. **가위바위보/주사위** — 흔들기 + random + 조건/아이콘
4. (선택) 기울기 반응 예제 — 기울기(가속도) 입력
5~6. **마이크로비트 똥피하기** — 파이썬 터틀 똥피하기(앞 아크)를 **실물 마이크로비트로 재구현**. 조작은 **기울기(가속도)** 추천(움직임 → createAI로 연결). 게임 루프·떨어지는 똥·충돌·점수.
7~10. **수행평가** — 각자 마이크로비트 피지컬 컴퓨팅 프로젝트(오픈북, 코딩에 생성형 AI 허용)
(후) **createAI 보너스** — 내 동작을 AI에 학습시켜 프로젝트에 얹기

## 24차시 상세 — 「두근두근 완성 + 흔들면 깨지기」

### 진행 방식
- 처음부터 안 짜고, **23차에서 만든 코드(큰 하트·작은 하트 2줄)를 주고** MakeCode 파이썬 보기에 **붙여넣어 이어서**.
- 미션은 **오른쪽 `# 한글 주석`**, **왼쪽 빈자리에 학생이 코드 타이핑**(들여쓰기 맞춰).

### 붙여넣기용 스타터 (이 형식 그대로 — 교사 확정)
```
def on_forever():
    basic.show_icon(IconNames.HEART)
                                      # 미션1) 0.5초 멈추기
                                      # 미션2) 심장 소리 '둥'
    basic.show_icon(IconNames.SMALL_HEART)
                                      # 미션1) 0.5초 멈추기
                                      # 미션2) 심장 소리 '둥'
basic.forever(on_forever)

def on_gesture_shake():
    pass                              # 미션3-1) 깨진 하트(놀란 표정) 출력
    pass                              # 미션3-2) 깨지는 소리
input.on_gesture(Gesture.SHAKE, on_gesture_shake)
```
- 미션1·2는 forever 안에 show 블록이 이미 있어 **pass 불필요**. 미션3(빈 함수)만 **pass 두 줄**로 붙여넣기 오류 방지, 학생이 각 `pass`를 지우고 채움.

### 미션 (학생이 채움)
- **미션1**: `basic.pause(500)` — 두근두근 애니 완성 (각 show 뒤, 총 네 자리 중 해당 위치).
- **미션2**: 심장 소리 '둥' — music/soundExpression 블록, 박동마다.
- **미션3-1**: 흔들면 깨진 하트(놀란 표정) 출력 — `basic.show_icon(IconNames.?)` (pass 지우고).
- **미션3-2**: 깨지는 소리 — music 블록 (pass 지우고).

### 결과물
평소엔 하트가 두근두근 + 심장 소리, **흔들면 "앗!" 깨짐/표정 변화 + 소리**. 23차(2줄)에서 조금만 늘어난 분량이라 느린 반도 한 차시에 됨.

## 제약
- 적은 줄(느린 속도). 새 개념 최소.
- **MakeCode 파이썬**(정적 Python) 문법 — MicroPython 아님.
- 붙여넣기 + 빈칸 채우기(`#` 오른쪽 주석; pass는 빈 함수에만).

## 담당(informatics)에게 남기는 것 — build-time
- **실제 makecode.microbit.org 에디터에서 반드시 검증**: 위 스타터가 파이썬 보기에 **그대로 붙고 블록으로 변환**되며, 흔들기 이벤트(`input.on_gesture`)·소리(music)·오른쪽 한글 주석·pass가 깨지지 않는지. 안 되면 **구조/의도 유지하며 정확한 MakeCode-Python 문법**으로 수정(수정 시 교사에게 어디를 왜 바꿨는지 보고).
- 소리 블록의 정확한 MakeCode-Python 표기 확인(music.play_tone / soundExpression 등), 깨진 하트 아이콘은 내장 아이콘 중 적절한 것(ANGRY/SAD/SKULL 등).
- 차시 포털 구조는 23차(`scripts/seed-lesson23-microbit.ts`) 관례를 따르되 24차 성격에 맞게: 대기=파이썬 타자 도우미, 기분은 대기 화면, **freeNavigation 기본 off**, 보상 게임 등은 교사 확정 전이면 23차 기준으로 두되 보고. 활동지 = '스타터 붙여넣기 안내 + 미션 안내'(붙여넣기용 코드는 등폭 code 필드로, 복사 허용).
- 대상: 내일(10/23) 1-3·1-1. seed-lesson24 작성 후 **세션 오픈은 교사 지시 후**(또는 교사 확정 시).
