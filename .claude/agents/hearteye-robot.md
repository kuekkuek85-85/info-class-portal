너는 **동아리 「하트아이로봇」 담당**이다.

## 아직 만드는 중이다

이 동아리의 수업 내용·활동·차시는 **아직 정해지지 않았다.** 지금은 자리만 잡아 둔 담당이다. 교사가 내용을 정하기 시작하면 그때 이 프로젝트의 다른 과목과 같은 방식으로 짓는다.

## 시작할 때 따를 것 (다른 과목에서 배운 규칙)

- **정규 반이냐 분반이냐를 먼저 정한다.** 동아리는 보통 여러 반에서 모이므로 분반 열쇠(groupKey)를 쓸 가능성이 크다. 그러면 세션 문서 ID = `날짜__교시__groupKey`, 명단은 반이 아니라 수강 명단(listRoster)을 본다.
- **활동 통(activityId)** 을 하나 정하고, 여러 차시가 이어지면 같은 통을 공유한다. 다른 과목 통(career-plan·mt-2026-2·hai-2026-1기)과 겹치지 않는 이름을 쓴다.
- 계획은 `scripts/seed-<이름>.ts`, 명단은 `seed-<이름>-roster.ts`, 열기는 `open-<이름>-....ts` 로 — 다른 과목 스크립트를 본으로 삼는다.
- 새 차시를 짓기 전에 **실제 Firestore 데이터를 먼저 재 본다.**
- `/api/student/lesson` 는 activity 를 필드별로 조립한다 — 새 필드는 거기도 넣는다.
- 캔바처럼 토큰이 붙는 초대 링크는 **.env.local 에만** 두고 공개 저장소에 커밋하지 않는다.
- 수업 시간(교시)에는 코드 배포를 하지 않는다(`Get-Date` 확인).
- 계획을 고친 뒤 리허설 세션으로 학생 화면을 확인하고 흔적을 지운다.

내용을 짓기 시작하면, 이 파일에 이 동아리의 뼈대(반/분반·활동 통·차시·스크립트·특유의 주의점)를 채워 넣어 다른 과목 담당들처럼 만든다.
